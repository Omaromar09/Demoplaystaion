# 🎮 XO PS Lounge - الموقع الإلكتروني الرسمي (نسخة ديمو)

موقع إلكتروني متكامل وعصري لمحل وبلايستيشن لاونج **XO PS (اكس او بي اس)**، يجمع بين طابع الألعاب الهادئ وأجواء القهوة الفاخرة والاسترخاء.

> **💡 تنويه**: هذا الموقع عبارة عن **نسخة ديمو تجريبية (Demo)** من عمل وإشراف **بشمهندس ياسين** وفرقة [7pstudio](https://7pstudio.tech).

---

## 🌟 أبرز التحديثات والمميزات الجديدة

### 1. ☕ ألوان هادئة مستوحاة من القهوة والهدوء
- اعتماد درجات **البني الإسبريسو الفاخر (`#140E0C`)** والكراميل الدافئ (`#C69255`) وعسل الكريما (`#E0A96D`).
- إزالة السواد القاتم، واستبدال الأبيض الصريح بلون **أوف وايت كريمي راقٍ (`#F5EFEB`)**.
- إلغاء الألوان الفاقعة والنيون الحاد ليصبح المظهر دافئاً ومريحاً للعين لساعات طويلة.

### 2. 🎮 شاشة تحميل مميزة مع صوت تشغيل البلايستيشن
- شاشة لودينج مع **ذراع تحكم بلايستيشن (جويستيك) متحرك وثلاثي الأبعاد** مع أزرار مضيئة.
- محاكاة دقيقة وحقيقية لـ **نغمة بداية تشغيل البلايستيشن (PlayStation Startup Chime)** تم توليدها برمجياً عبر Web Audio API بنقاء صوتي مذهل.

### 3. 📌 أيقونة الحجز الجانبية العائمة
- زر عائم على جانب الشاشة بمظهر عصري يتيح للعميل الحجز السريع في أي وقت ومن أي مكان بالصفحة بضغطة واحدة.

### 4. 🎫 نظام الفاوتشرز وأكواد الخصم (Vouchers)
- **أيقونة الفاوتشرز في الهيدر**: تظهر عدد الفاوتشرز المتاحة لحساب العميل.
- نافذة مخصصة للفاوتشرز توضح:
  - كود الخصم (مثل: `XO-COFFEE20` أو `FREE-ESPRESSO` أو `GAMER-50EGP`).
  - قيمة الخصم وتفاصيله.
  - مدة صلاحية الفاوتشر وتاريخ الانتهاء المتبقي بدقة.
  - إمكانية تطبيق الخصم مباشرة داخل خطوات الحجز ليتم خصمه من الإجمالي تلقائياً.

### 5. 🚫 إزالة الواتساب بالكامل
- تم إلغاء خانة الواتساب وأزراره بالكامل والاعتماد على الحجز الإلكتروني الفوري وإصدار التذاكر الرقمية المباشرة بـ QR Code.

### 6. 🛋️ وصف راقٍ وبسيط للمكان
- مقدمة واضحة بدون أي تعقيد توضح فكرة المكان وهدوءه وخدمة كافيه الريست بكل بساطة.

## 🚀 كيفية تشغيل الموقع
انقر نقراً مزدوجاً على ملف `index.html` في أي متصفح (Edge, Chrome, Firefox) وسيعمل الموقع بكامل طاقته ومؤثراته فوراً.
